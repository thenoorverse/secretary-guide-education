💡 1. مفهوم السكرتارية في التعليم

السكرتير هو العمود الفقري للإدارة المدرسية وحلقة الوصل بين المدير والمعلمين والطلاب وأولياء الأمور.

📋 2. المهام والمسؤوليات

نظّم عملك بدورات زمنية واضحة حتى لا يضيع شيء في الزحام.

☀️ يومياً
فتح المكتب، البريد الوارد، جدول المدير، الغياب، الرد على الاستفسارات، المذكرات والتعاميم.
📅 أسبوعياً
محاضر الاجتماعات ومتابعة القرارات، تحديث قواعد البيانات، مراجعة المخزون، التقرير الأسبوعي.
🗓 شهرياً
الإجازات والرواتب، ملفات الاختبارات، النتائج، إحصائيات الغياب والنجاح، ملفات الجودة.
🎓 سنوياً
القبول والتسجيل، الجداول الدراسية، الجرد السنوي، إغلاق الأرشيف.

🛠 3. المهارات الاحترافية

⌨️ مكتبية
طباعة 40 كلمة/دقيقة، Word وExcel (SUM, AVERAGE, COUNTIF, VLOOKUP)، العروض والبريد.
📞 اتصال
الرد خلال 3 رنات، الإنصات وتدوين الملاحظات، الصياغة الرسمية، ضبط النفس مع الشكاوى.
🤝 شخصية
السرية، الدقة، إدارة الوقت، المبادرة تحت الضغط، المظهر اللائق.
النموذج الاحترافي للرد: «السلام عليكم، مدرسة [الاسم]، معك [اسمك] سكرتارية الإدارة، كيف أقدر أخدمك؟»

🏢 4. إدارة مكتب المدير

  1. جدول المواعيد: تقويم مشترك، وثّق الاسم والجهة والموضوع والمدة، واترك 15 دقيقة فاصلة.
  2. فلترة الزوار: عاجل / مهم / يُؤجّل / يُحوّل للوكيل. لا إدخال دون استئذان.
  3. ملف التوقيع: أقسام (للتوقيع / للمراجعة / للعلم) مع لاصقات، max عشر معاملات دفعة واحدة.
  4. التذكير الاستباقي: قبل الاجتماع بساعة وقبل الموعد الخارجي بيوم مع تجهيز الملفات.

✉️ 5. المراسلات والصياغة الرسمية

عناصر الخطاب: الترويسة والشعار ← رقم الصادر والتاريخ ← الموجّه إليه ← الموضوع ← مقدمة وعرض وخاتمة ← التوقيع والختم ← المرفقات.

⚠️ تجنّب: الأخطاء الإملائية، الحشو والإطالة، العامية والرموز التعبيرية، نسيان المرفقات، الإرسال دون مراجعة ثانية.

👥 7. الاجتماعات + 8. شؤون الطلاب

قبل الاجتماع: دعوة + جدول أعمال قبل 48 ساعة، تجهيز القاعة وقائمة الحضور.
أثناء: تسجيل الحضور والقرارات والتكليفات (من/ماذا/متى).
بعد: محضر + متابعة التنفيذ وتذكير المعنيين.
الطلاب: دقق الهويات وملفات الانتقال، رقم موحد لكل طالب، رصد الغياب وإشعار الولي، الشهادات بتوقيع وختم وسجل خاص، بيانات صحية وأسرية سرية تماماً.
ولي أمر الطالب (...) المحترم نفيدكم بأن ابنكم تغيب يوم ... دون عذر، نأمل التواصل مع الإدارة خلال 48 ساعة. شاكرين تعاونكم. إدارة المدرسة

📝 9. الاختبارات — المهمة الأكثر حساسية

🔒 استلام الأسئلة بمظاريف مختومة + خزانة مقفلة + سجل استلام وتسليم.
📑 تجهيز: الجداول، المناداة، أرقام الجلوس، محاضر فتح المظاريف والغياب والغش.
👁 تنظيم لجان المراقبة والتصحيح والرصد.
✅ مطابقة الكشوف مع الأوراق قبل الإعلان + نسخة معتمدة محفوظة.
⛔ أي تسريب أو خطأ رصد = مسؤولية مباشرة. الدقة غير قابلة للمساومة.

💬 10-12. أولياء الأمور • التقنية • الوقت

🤝 أولياء الأمور
رحّب وقف وعرّف بنفسك. أنصت دون مقاطعة: «أتفهم قلقكم وسنتابع». حدد موعد رد والتزم به. لا تناقش مستوى طالب أمام الآخرين.
💻 سكرتير رقمي
أنظمة نور/فارس/مدرستي، البريد الرسمي، Sheets للتقارير، Drive للنسخ، Zoom/Teams، كلمات مرور قوية وعدم فتح روابط مجهولة.
⏰ مصفوفة الأولويات
مهم+عاجل ← نفّذ فوراً. مهم+غير عاجل ← جدول له. غير مهم+عاجل ← فوّض. غير مهم+غير عاجل ← احذف. ابدأ بأصعب مهمة + ساعة باب مغلق يومياً.

🛡 13. الأخلاقيات + 14. الأزمات

الأخلاقيات: السرية — ما يُسمع في مكتب المدير يبقى فيه • الحياد والعدالة • النزاهة ورفض الهدايا مقابل الخدمات • القدوة في الدوام • الولاء وعدم نقل الأسرار.
الطوارئ: أرقام الطوارئ وقوائم الطلاب مطبوعة وجاهزة • حالة صحية: إسعاف + ولي الأمر + توثيق • بدائل ورقية عند انقطاع النظام • الشائعات: لا تعليق، حوّل للمدير • تقرير بعد كل أزمة.
السكرتير يرى كل شيء ويسمع كل شيء ويقول فقط ما يجب قوله.
